# OFFSIDE 設計メモ

架空のサッカークラブのオーナーとなり、八百長・買収・脅迫・資金洗浄・暗殺など、あらゆる手段でクラブを大陸の頂点へ押し上げるブラウザゲーム。

このメモは議論で決まったことを記録する。未決の項目は「未決」に置く。

## 決定事項

| 項目 | 内容 |
|---|---|
| タイトル | OFFSIDE |
| 型 | 経営シム+裏工作。1週ごとに進行 |
| 試合 | 中継テキスト+要所で仕込んだ工作を発動 |
| トーン | 硬派なノワール。暴力はある程度具体的に描く(凄惨にはしない) |
| 世界 | 架空の欧州風国家。実在のクラブ・選手は使わない |
| 目標 | 大陸大会の優勝 |
| 敗北 | 起訴され、裁判イベントを越えられなければ終了 |
| 裏工作 | 八百長・審判買収/脅迫・情報操作/財務不正・マネロン/妨害・暴力・暗殺 |
| 実行 | 手駒(人物)に任せる |
| 捜査 | 複数の追及者がそれぞれ証拠を集める |
| UI | 表=放送グラフィック、裏=捜査資料・機密書類 |
| 配色 | 表:地 #0E0F11 / 文字 #ECEAE4 / 差し #D0342C。裏:紙 #E6DFCF / 墨 #1B1A17 / 印 #A8241C |
| 書体 | 表:細いサンセリフ+数字は等幅/コンデンス。裏:明朝+タイプライター風の等幅 |
| 演出 | 多め。ただしすべてクリック・キーで飛ばせる |
| 音 | 効果音のみ(コードで合成)。初期は無音、設定で有効化 |
| 言語 | 日本語+欧文の飾り(見出し・印字・テロップのラベル) |
| 素材 | 画像なし。文字と図形で表現 |
| 端末 | PCブラウザが主、スマホにも対応 |
| ボリューム | 1シーズン10〜15分(リーグ10〜14節)。二部開始で5〜8シーズン |
| 保存 | ブラウザに自動保存 |

## 開始時の選択

**経歴**
- 実業家:表の資金が多い。財務工作が得意
- 元代表選手:協会・選手とのコネ。八百長が得意
- 港湾組合の顔役:最初から暴力系の手駒がいる。最初から検察に目をつけられている

**クラブ**
- 三部の地方クラブ(長い)
- 二部の没落した名門(標準)
- 一部の中堅(短い)

**経営モード**
1. オーナー:監督の任免、予算、移籍の承認のみ
2. 会長:上に加え、移籍交渉、契約、チーム方針(数種類)
3. 全権:上に加え、先発メンバーと試合中の交代・戦術変更

## 中心の仕組み(案)

**資源**:表の資金、裏金、影響力(審判・協会・警察・記者とのつながり)。

**手駒**:腕・忠誠・口の堅さ・週額と、隠れた弱みを持つ。
- 成否は腕、痕跡の量は口の堅さで決まる
- 忠誠が下がると追及者に寝返って証言する
- 口を割りそうな手駒は別の手駒に「片付けさせる」ことができる。片付けるたびに組織は痩せ、新たな痕跡が残る

**追及者**:検察特捜部、協会倫理委員会、調査報道の記者、ライバルクラブのオーナー。証拠が閾値を越えると固有の行動を起こす(家宅捜索、勝ち点剥奪、スクープ、逆工作)。追及者ごとに買収・妨害・排除が可能。

**つながり**:工作の結果は表のニュースや試合に現れる(例:相手主将への細工 → 負傷報道 → 欠場 → 買収した主審の判定)。
