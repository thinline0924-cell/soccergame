# OFFSIDE 設計メモ

架空のサッカークラブのオーナーとなり、八百長・買収・脅迫・資金洗浄・暗殺など、あらゆる手段でクラブを大陸の頂点へ押し上げるブラウザゲーム。

このメモは議論で決まったことを記録する。未決の項目は「未決」に置く。

## 開始時の選択

**経歴**
- 実業家:表の資金が多い。財務工作が得意
- 元代表選手:協会・選手とのコネ。八百長が得意
- 港湾組合の顔役:最初から暴力系の手駒がいる。最初から検察に目をつけられている

**クラブ**
- 三部の地方クラブ(長い)
- 二部の没落した名門(標準)
- 一部の中堅(短い)

**経営モード**
1. オーナー:監督の任免、予算、移籍の承認のみ
2. 会長:上に加え、移籍交渉、契約、チーム方針(数種類)
3. 全権:上に加え、先発メンバーと試合中の交代・戦術変更

## 中心の仕組み(案)

**資源**:表の資金、裏金、影響力(審判・協会・警察・記者とのつながり)。

**手駒**:腕・忠誠・口の堅さ・週額と、隠れた弱みを持つ。
- 成否は腕、痕跡の量は口の堅さで決まる
- 忠誠が下がると追及者に寝返って証言する
- 口を割りそうな手駒は別の手駒に「片付けさせる」ことができる。片付けるたびに組織は痩せ、新たな痕跡が残る

**追及者**:検察特捜部、協会倫理委員会、調査報道の記者、ライバルクラブのオーナー。証拠が閾値を越えると固有の行動を起こす(家宅捜索、勝ち点剥奪、スクープ、逆工作)。追及者ごとに買収・妨害・排除が可能。

**つながり**:工作の結果は表のニュースや試合に現れる(例:相手主将への細工 → 負傷報道 → 欠場 → 買収した主審の判定)。

## 工作の一覧

| 系統 | 工作 | 効果 | 痕跡 |
|---|---|---|---|
| 八百長 | 審判への謝礼 | 試合中、際どい判定を1回動かせる | 小 |
| | 相手選手の買収 | 特定の選手が手を抜く | 中 |
| | 試合ごと買う | 相手と談合し勝ちがほぼ確定 | 大 |
| | 賭けの裏張り | 次の試合に賭けて裏金を稼ぐ | 中 |
| 脅迫・情報 | 身辺を洗う | 対象の弱みを得る | なし |
| | 脅す | 弱みで相手を一度動かす | 小 |
| | 追及者の買収 | 証拠を減らし、しばらく黙らせる | 中 |
| 財務 | 裏金を作る | 入場料の抜き取りなど | 中 |
| | 洗浄 | 裏金→表の資金(手数料あり) | 中 |
| | 粉飾 | 債務の取り立てを先送り | 大 |
| 暴力 | 警告 | 一時的に追及を止める/脅しを強める | 中 |
| | 負傷させる | 対象が数週欠場 | 中〜大 |
| | 消す | 対象がゲームから消える | 最大 |
| | 口を封じる | 自分の手駒を消し、その証言も消す | 大 |

## 痕跡と追及

- 工作ごとに痕跡が残り、実行した手駒に紐づく
- 追及者は毎週、得意分野の痕跡を拾う(検察=金と暴力、記者=人の噂、倫理委員会=試合の不自然さ、ライバル=試合と人)
- 証拠 40 で動き出し、70 で固有の行動、100 で決定的な処分。検察 100 で起訴
- 追及者を消すと追及はいったん止まるが、後任はより強硬になる

## 裁判

有罪率 = 検察の証拠 × 生きている証人の数 × 司法への影響力。判決前に一度だけ手を打てる。無罪なら検察の証拠が大きく下がり、有罪ならゲームオーバー。

## 試合

1試合は10〜15の局面。各局面を両チームの力と工作の効果で判定し、実況文にする。介入は局面単位で、1試合は約1分。早送り可。

## 手番

手駒1人につき1週1件。手駒の数が1週にできる工作の量になる。

## 試作の範囲(第1段階)

二部・実業家・会長モードの1通りで、1シーズン(8クラブ2回戦総当たり=14週)。経営、工作、追及、試合、裁判、終了条件(起訴後の有罪、暗殺、破産)、昇格判定まで。

## 改訂(第2段階):案件駆動へ

初版は「工作メニューを自由に選ぶ」形だったが、目的・結果・物語が見えず単調だった。以下に作り直した。

- **案件(ドシエ)**:毎週2〜3件、具体的な事件が書類で届く(例:次節の主審の借金、相手主力の引き抜き話、嗅ぎ回る記者)。各案件に表/裏の選択肢があり、誰が動くか・何を失うかを明示。選ぶとすぐ文章で結果が返る。
- **状況バー**:順位・次節・最大の脅威・「今の勝負どころ」を常時表示。
- **連続した筋**:記者の調査、ライバルとの抗争などがシーズンを通して段階的に進む(`cases.js` の thread)。
- **試合の決断**:ハーフタイム・終盤・買収した審判の前で2〜3回。仕込んだ工作は試合開始時に可視化し、効き目を実況に出す。
- **試合後のまとめ**:結果・仕込みの効果・収支・追及の動きを一覧で見せてから新聞へ。

ファイル構成に `js/cases.js`(案件の内容)と `js/engine.js`(抽選・解決・状況要約)を追加。旧 `js/ops.js` は廃止。
