# OFFSIDE

架空のサッカークラブのオーナーとなり、八百長・買収・脅迫・資金洗浄、そして最後の手段まで ―― あらゆる手を使って、捕まる前にクラブを頂点へ押し上げる経営ノワール。ブラウザだけで遊べます。

二部の没落した名門 **US ヴェラルド**。正攻法で上がれる戦力はありません。14節のうちに上位2位へ入り、一部へ昇格すること。ただし、手を汚すたびに痕跡が残り、4人の追及者(検察・記者・協会・ライバル)がそれを拾っていきます。検察の証拠が積み上がれば起訴され、公判は一発勝負です。

## 遊び方

- **表(クラブハウス)**:選手、移籍、チーム方針を決め、「週を進める」と試合があります。
- **裏(ファイル)**:手駒に工作を命じます。手駒は1週に1件まで動けます。
- 工作には **成算** と **痕跡** があり、痕跡は実行した手駒に残ります。
- 手駒は忠誠が下がると寝返り、検察の証人になります。危うい手駒は口を封じることもできますが、それもまた痕跡になります。
- 試合中、買収した審判がいると「介入」の場面が来ます(制限時間は設定で外せます)。

勝っても負けても、捕まらずに頂点へ。

## 公開(Render 静的サイト)

HTML・CSS・JavaScript だけでできているので、Render の静的サイトとして無料で公開できます。設定は `render.yaml` にあります。

1. https://dashboard.render.com にログイン
2. **New +** → **Blueprint**
3. リポジトリ **thinline0924-cell/soccergame** を選ぶ
4. 表示される Static Site で **Apply**
5. 1〜2分で公開完了。`https://offside-xxxx.onrender.com` のような URL で遊べます

`main` に変更が入ると自動で公開し直します。

> `index.html` をダブルクリックして直接開くと、ブラウザの制限(ES モジュール)で動きません。Web サーバー経由で開いてください。ローカルなら `python3 -m http.server` などが使えます。

## 構成

素の JavaScript(ES モジュール)。ビルドもライブラリも不要です。

| ファイル | 役割 |
|---|---|
| `js/data.js` | クラブ・選手・手駒・追及者・工作の定義 |
| `js/state.js` | ゲーム状態、保存・読み込み |
| `js/ops.js` | 工作の成算・解決・痕跡 |
| `js/pursuit.js` | 追及者の動き、裁判、終了条件 |
| `js/match.js` | 試合シミュレーション |
| `js/world.js` | 週送りの全体処理 |
| `js/ui.js` `js/flow.js` `js/main.js` | 画面と操作 |
| `js/sound.js` | 効果音(コード合成、初期は無音) |

設計のメモは `docs/DESIGN.md` にあります。
